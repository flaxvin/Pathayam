Forwarding address add-on

Get an address like u-7f3a@in.pathayam.app and set one filter in your mail client. Bank alerts and statement emails land in your review queue within seconds of arriving — without this app ever having access to your inbox.

Nothing forwarded is kept beyond 90 days. A message is parsed into a review row and the original is deleted on that schedule, whatever happens. That window is a promise, not a setting — a mailbox of other people's bank mail piling up indefinitely is the worst thing this service could quietly become.

Questions worth answering first

Is the self-hosted version crippled?

No, and it never will be. Self-hosting gets every feature including the ones the hosted tiers do not have — Gmail ingestion among them. What you pay for is somebody else doing the backups, the updates and the 2am worrying.

Why is Gmail missing from the hosted plans?

Reading your inbox needs a Google permission tier that requires an annual third-party security audit for any public service. That is months of somebody else's calendar and a five-figure recurring cost, and it would have to be priced into every plan including the ones nobody uses it on.

The forwarding add-on gets most of the same result the other way round: you push the mail to us, rather than us reaching into your inbox. If you want the real thing, self-host — you consent to your own Google project and none of this applies to you.

Where does my data actually live?

On a hosted plan, in its own database in an Indian region — one container and one file per customer, not a shared table with your row in it. Self-hosted, wherever you put it.

Can I get my data out?

One endpoint returns everything in an open format, any time, on every plan. The database is a SQLite file you can open with anything. Cancelling gets you the file.

This is deliberate and it is tested: the export is asserted complete by the test suite. Software that is hard to leave is software that has stopped trying to be worth staying with.

Is there a free trial?

There is a live demo with three years of data you can change however you like, and there is a free version you can run forever. Between them you can answer every question about whether this suits you before paying anything.

What happens if you stop?

The software is open source and the data format is documented, so the worst case is that you move the file to your own machine and carry on. That is the reason the free tier stays unlimited: it is what makes the hosted tier safe to buy.
